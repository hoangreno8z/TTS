# SOURCE INDEX

## 1. F5-TTS — Official
https://github.com/SWivid/F5-TTS
Vai trò: engine benchmark chính.
Code MIT; upstream README hiện ghi pretrained models có CC-BY-NC do dữ liệu Emilia. Kiểm tra model cụ thể trước khi dùng.

## 2. GPT-SoVITS — Official
https://github.com/RVC-Boss/GPT-SoVITS
Vai trò: engine benchmark đối chứng/few-shot.
Repo có CLI/API inference và nhiều release. Kiểm tra version/model license cụ thể.

## 3. OpenVoice — Official
https://github.com/myshell-ai/OpenVoice
Vai trò: benchmark bổ sung về tone color/style.
README công bố V1/V2 MIT; V2 native support được nêu cho English, Spanish, French, Chinese, Japanese, Korean — không coi đó là native Vietnamese support.

## 4. F5-TTS Vietnamese
https://github.com/psilabvnorg/F5-TTS-Vietnamese
Vai trò: tham khảo pipeline Vietnamese + FastAPI + fine-tuned model.
Không coi fork/community repo là upstream.

## 5. F5-TTS Vietnamese fine-tuning
https://github.com/hipleonas/f5-tts
Vai trò: tham khảo fine-tuning Vietnamese F5-TTS.
Các con số về dữ liệu trong repo là kinh nghiệm của tác giả, không phải yêu cầu bắt buộc của dự án cá nhân.
